# Инварианты и процедура эталонной проверки

Пусть состояние клиента $C_Q=\{f_1,f_2,\ldots,f_s\}$, где каждый материализованный фрагмент имеет вид $f_i=(I_i,Rows_i,v_i)$, а $F_i=F(Q,I_i,v_i)$ - эталонный фрагмент для того же запроса, диапазона и watermark.

Клиентское представление считается корректным, если выполняются следующие инварианты.

## Инварианты

### 1. Уникальность `rowId`

Количество различных `rowId` во всём материализованном состоянии клиента должно совпадать с количеством хранимых строк:

```math
\left| \{ rowId(r) \mid \exists i:\ r \in Rows_i \} \right|
=
\sum_i |Rows_i|
```

### 2. Принадлежность диапазону

Каждая строка фрагмента принадлежит его диапазону: $\forall r\in Rows_i:\ r\in I_i$.

### 3. Корректный порядок

Пусть $Rows_i=\langle r_1,r_2,\ldots,r_n\rangle$. Каждая следующая строка расположена позже предыдущей согласно порядку $\prec_Q$:

$$
\forall j\in\{1,\ldots,n-1\}:\ r_j\prec_Q r_{j+1}.
$$

### 4. Полнота диапазона

Набор строк клиентского фрагмента совпадает с эталонным фрагментом по `rowId`:

$$
Ids(Rows_i)=Ids(F_i).
$$

### 5. Корректность значений

Для каждой строки клиентского фрагмента существует строка эталонного фрагмента с тем же `rowId` и теми же значениями:

$$
\forall r\in Rows_i\ \exists r'\in F_i:
rowId(r)=rowId(r')
\land
Values(r)=Values(r').
$$

### 6. Непересечение материализованных диапазонов

Диапазоны различных фрагментов не пересекаются: $\forall i\ne j:\ I_i\cap I_j=\varnothing$.

## Процедура эталонной проверки

Проверка выполняется через barrier для выбранного watermark $V$.

1. Остановить генератор изменений.
2. Дождаться завершения всех начатых атомарных групп изменений и зафиксировать текущий watermark $V$.
3. Довести клиентский event stream до barrier $V$.
4. После достижения barrier $V$ каждый проверяемый фрагмент должен иметь вид $f_i=(I_i,Rows_i,V)$.
5. Для каждого материализованного диапазона $I_i$ вычислить эталонный фрагмент из состояния $D_V$: $F_i=F(Q,I_i,V)$.
6. Для каждого фрагмента проверить:
   - принадлежность всех строк диапазону $I_i$;
   - совпадение набора `rowId` с $F_i$;
   - совпадение значений строк с $F_i$;
   - корректный порядок строк.
7. Для всего состояния клиента проверить глобальную уникальность `rowId` и непересечение материализованных диапазонов:

Клиентское состояние на watermark $V$ считается корректным, если все проверки выполнены успешно.
