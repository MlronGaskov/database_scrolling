# Набор инвариантов и процедура эталонной проверки

Пусть $C(Q,I,v)$ - материализованный на клиенте фрагмент результата запроса $Q$ для диапазона $I$ и версии $v$, а $F(Q,I,v)$ - эталонный серверный фрагмент для того же запроса, диапазона и версии.

Клиентское представление считается корректным, если выполняются следующие инварианты:
1. **Полнота диапазона.** Клиент содержит все и только те строки, которые входят в эталонный серверный фрагмент: $Ids(C(Q,I,v)) = Ids(F(Q,I,v)).$
2. **Совпадение значений.** Для каждой строки значения на клиенте совпадают со значениями на сервере: $\forall r \in C(Q,I,v):\ C[r]=F[r].$
3. **Совпадение порядка.** Последовательность идентификаторов строк на клиенте совпадает с эталонной серверной последовательностью: $Order(C(Q,I,v)) = Order(F(Q,I,v)).$
4. **Отсутствие дубликатов.** Каждый идентификатор строки встречается во фрагменте не более одного раза: $\forall id:\ count_C(id)\leq 1.$
5. **Согласованность версии.** Клиентский и эталонный фрагменты сравниваются для одной и той же логической версии $v$.

### Процедура эталонной проверки

Для каждого материализованного клиентского фрагмента $C(Q,I,v)$:
1. На сервере вычислить результат запроса $Q$ для состояния данных версии $v$.
2. Выделить из результата эталонный диапазон $F(Q,I,v)$.
3. Сравнить множество идентификаторов строк.
4. Сравнить значения строк.
5. Сравнить порядок строк.
6. Проверить отсутствие дубликатов.
Фрагмент считается корректным только при выполнении всех проверок.
