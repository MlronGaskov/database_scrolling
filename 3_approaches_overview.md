# Обзор базовых подходов и критерии сравнения

Для актуализации частичных результатов рассматриваются четыре базовых подхода.

Критерии сравнения:
1. **Объём передаваемых данных** - количество данных, передаваемых при начальном получении и последующей актуализации.
2. **Задержка актуализации** - время между изменением данных на сервере и отражением изменения на клиенте.
3. **Объём данных на клиенте** - требуется ли хранить полный результат или только выбранный фрагмент.
4. **Повторные чтения** - необходимость повторного получения данных для поддержания или восстановления актуального состояния.
5. **Поддержание порядка** - возможность корректно поддерживать упорядоченный результат при изменениях данных.
6. **Восстановление после разрыва** - способ восстановления актуального состояния после временной потери связи.
7. **Серверные затраты** - вычислительные и ресурсные затраты сервера на получение результата и поддержание его актуальности.
